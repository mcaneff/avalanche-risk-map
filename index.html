From regional danger levels to individual slopes

Avalanche bulletins give one danger level for a whole region. This project asks two questions. First, can a danger-level model trained on weather stations run on a gridded weather forecast instead, so it works anywhere? Second, can that weather signal be combined with 10 m terrain to say which slopes release on a given day?

The map shows the first answer for the canton of Grisons, Switzerland: the model's danger level for every weather-model grid cell, next to the official bulletin for the same day. Pick what each map shows, step through two test winters with the day slider, and click anywhere for the numbers. The two maps pan and zoom together.

Method

Four stages, one model

01Station model

Weather encoder

A transformer reads 30 days of weather station data and predicts the regional danger level. Its trunk becomes the weather half of the slope-scale model.

IMIS stations · SLF bulletins

02Gridded forecast

Station to grid

The same trained weights, fed by a numerical weather model instead of a station, so a danger level can be produced for every grid cell rather than only where a station stands.

Meteoblue NEMS4 · 4.45 km · 352 cells

03Terrain

Terrain inputs

Eight 10 m layers for all of Grisons: slope, canopy, release areas, travel angle, flow cell counts, elevation drop, route flux and elevation.

8 channels · 71 million cells

04Slope-scale model

Two-tower U-Net

A terrain U-Net whose features are modulated by the day's weather embedding. Output: the probability that each 10 m cell releases on that day.

12,577 mapped avalanches · 17 winters

Results

Station weather against weather-model weather

The same trained model scores the same 9,766 test station-days (winters 2018/19 and 2019/20) twice: once with the station's own measurements, once with the weather model's values at the nearest grid point. Only the weather source changes, so the gap between the two is the cost of forecasting where there is no station. The true level is the bulletin level for the station's region.

Rows: true level. Columns: predicted level. Numbers are station-days; shading is the share of each row.
